spinbutton widget

Shared directives, GtkWidget signals, state and general functions, and action conditions are summarized in the common widget contract. The sections below document this tag's specific surface.

A GtkSpinButton

Definition 

<spinbutton tag_attr="value"...>
	<default>value</default>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<sensitive>state</sensitive>
	<action>activity</action>...
	<action signal="type">activity</action>...
	<action function="type">parameter</action>...
	<output file>filename</output>
</spinbutton>

"..." denotes acceptance of multiples of the same thing.

Tag Attributes

See the GtkSpinButton widget and ancestor class properties.

The following custom tag attributes are available:

Name Description Value Since
space-expand Pack widget expanding into space true or false Legacy
space-fill Pack widget filling space true or false Legacy
block-function-signals Block signal emissions from functions true or false Legacy
file-monitor Emit signal when input file(s) change true or false 0.8.1
auto-refresh Auto refresh when input file(s) change true or false 0.8.1
range-min Minimum value A double precision floating point value Legacy
range-max Maximum value A double precision floating point value Legacy
range-step Step increment A double precision floating point value Legacy
range-value Initial value A double precision floating point value Legacy

Range attributes, the default directive and command or file input require complete finite numbers. range-min must be less than range-max, and range-step must be positive. Invalid range bounds fall back to 0..100, an invalid step falls back to 1, and other invalid numeric values are ignored with a warning.

Signals

The default signal is "value-changed", emitted when the range value changes.

The "changed" signal is emitted when typing into the entry.

The "activate" signal is emitted when the user activates the entry with the Enter key.

The "icon-press" and "icon-release" signals are emitted when an activatable icon is pressed or released, but these signal names will be prefixed with either "primary-" or "secondary-" to indicate the source icon.

The "file-changed" signal is emitted if file-monitor is true and the input file being monitored has changed.

The following signals are connected-up for all widgets:

button-press-event, button-release-event, configure-event, enter-notify-event, leave-notify-event, focus-in-event, focus-out-event, hide, show, realize, key-press-event, key-release-event, map-event, unmap-event

Type Description Argument Since
active_is_true(argument) Active state of toggle widget Variable name 0.8.3
active_is_false(argument) Active state of toggle widget Variable name 0.8.3

file_is_false(argument) Contents of a file Filename 0.8.3

visible_is_false(argument) Visible state of widget Variable name 0.8.3

variable_is_false(argument) Current textual value of widget Variable name 0.8.5

true means "true", "yes" or a complete non-zero decimal integer, while false means "false", "no" or a complete decimal integer equal to zero. Other output is neither true nor false.
