colorselection widget

An embedded GTK+ 2 GtkColorSelection. Unlike colorbutton, it exposes the full colour selector directly inside the application window.

Definition 

<colorselection has-opacity-control="true" has-palette="true"...>
	<default>#rrggbb|alpha</default>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<sensitive>state</sensitive>
	<action>activity</action>...
	<action signal="type">activity</action>...
	<output file>filename</output>
	<width>width-request</width>
	<height>height-request</height>
</colorselection>

Tag Attributes

Writable scalar properties of GtkColorSelection and its GtkWidget ancestors can be used as tag attributes. The most useful properties are:

NameDescriptionValues
has-opacity-controlShow alpha controls and include alpha in the exported valuetrue or false
has-paletteShow the shared GTK colour palettetrue or false
current-colorCurrent colour propertyGTK+ colour specification such as #4f81bd
current-alphaCurrent 16-bit alpha value0 to 65535
space-expandPack widget expanding into spacetrue or false
space-fillPack widget filling spacetrue or false
block-function-signalsBlock signal emissions from functionstrue or false
file-monitorEmit a signal when an input file changestrue or false
auto-refreshReload when an input file changestrue or false
context-menuPopup menu program for pointer or keyboard invocationExported variable containing a <popupmenu> program

Value and Directives

The value format matches colorbutton: #rrggbb without opacity controls, or #rrggbb|alpha when has-opacity-control is true. Alpha is a decimal integer from 0 through 65535. The same format is accepted by default, command input and file input, and is written by save to an output file. Invalid alpha values are ignored.

The width and height directives set size requests. The selector has no label, item, clear or remove-selection operation.

Signals and Functions

The default signal is color-changed. It is emitted whenever the current colour changes. The widget supports refresh and save in addition to the common visibility, sensitivity and focus functions. File monitoring provides the common file-changed signal and optional automatic refresh.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract.

Example 

<colorselection has-opacity-control="true" has-palette="true">
	<default>#4f81bd|49152</default>
	<variable>ACCENT_COLOUR</variable>
	<action>echo "$ACCENT_COLOUR"</action>
</colorselection>

This widget was introduced in version 0.9.0.
