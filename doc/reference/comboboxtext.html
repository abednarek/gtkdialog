comboboxtext widget

Shared directives, GtkWidget signals, state and general functions, and action conditions are summarized in the common widget contract. The sections below document this tag's specific surface.

A GtkComboBox. The established text-only model remains the default. An opt-in rich model can display per-item icons, markup and styling while exporting stable values that do not have to match the visible labels. Its hierarchical variant presents children as native GTK2 submenus.

Definition 

<comboboxtext tag_attr="value"...>
	<default>text</default>
	<variable>varname</variable>
	<input>command</input>...
	<input format="json">command</input>...
	<input file>filename</input>...
	<input file format="json">filename</input>...
	<sensitive>state</sensitive>
	<action>activity</action>...
	<action signal="type">activity</action>...
	<action function="type">parameter</action>...
	<item>data</item>...
	<output file>filename</output>
	<output file format="json">filename</output>
</comboboxtext>

"..." denotes acceptance of multiples of the same thing.

With item-model="rich", <default>, the widget variable and saved output use each item's value. A missing value falls back to the visible label, so ordinary items remain useful in the rich model. Command and file inputs similarly create unstyled items whose label and value are the input line. If more than one icon source is supplied, stock, themed and file icons are considered in that order. The rich model is not applied to comboboxentry, whose editable text contract remains unchanged.

item-model="rich-tree" uses a GtkTreeStore. Rows with children open native GTK2 submenus; only leaf rows are selected by automatic defaults. Plain saved output contains leaf values in depth-first order. Add format="json" to preserve the hierarchy and row presentation when loading or saving.

The JSON document deliberately follows the existing tree widget structure. Its root object contains integer version 1 and a rows array. Every row has a values array whose first value is the visible label and optional second value is exported; a missing second value falls back to the label. Optional members are children, stock-id, icon-name, markup, sensitive, and style. The style object accepts foreground, background, font and pixbuf-file. Setting sensitive false on a parent also makes its submenu inaccessible, so it is normally used on leaf rows.

Signals

The default signal is "changed", emitted when the active item is changed.

The "file-changed" signal is emitted if file-monitor is true and the input file being monitored has changed.

The following signals are connected-up for all widgets:

button-press-event, button-release-event, configure-event, enter-notify-event, leave-notify-event, focus-in-event, focus-out-event, hide, show, realize, key-press-event, key-release-event, map-event, unmap-event

Notes

This widget was introduced in version 0.7.21. Rich items were added in version 0.9.2, including hierarchical rich-tree models.

Example 

<comboboxtext item-model="rich" icon-size="20">
	<variable>ACTION_ID</variable>
	<default>open</default>
	<item value="open" stock="gtk-open" font="Sans Bold 9">Open document</item>
	<item value="save" stock="gtk-save" foreground="#204a87">Save document</item>
	<item value="offline" stock="gtk-disconnect" sensitive="false">Offline</item>
</comboboxtext>

See examples/comboboxtext/comboboxtext_rich for a runnable example. The comboboxtext_rich_tree example in the same directory loads nested rows from comboboxtext_rich_tree.json.
