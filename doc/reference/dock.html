dock widget

A rearrangeable GTK+ 2 workspace backed by the optional GDL 2 library. It owns one or more named dockitem panels without changing any historical gtkdialog container tag.

Definition 

<dock tag_attr="value"...>
	<dockitem>widget...</dockitem>...
	<variable>varname</variable>
	<input file>layout filename</input>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
	<output file>layout filename</output>
</dock>

At least one direct dockitem is required. The dockitems precede the dock directives in the XML, like child widgets in other gtkdialog containers.

Writable scalar GtkBox, GtkContainer and GtkWidget properties apply to the outer widget returned to gtkdialog. GDL's master, layout and child-object properties are managed by the dedicated attributes above.

Layout Files and Value

An input file loads a GDL XML layout during initialisation and on refresh. An output file receives the current layout when save is performed. Stable layout files require explicit, unique dockitem names. File monitoring and automatic refresh use the common widget facilities.

The exported dock variable is true after the current layout differs from its last loaded or saved state and false otherwise. There is no dock-specific clear or set-value operation.

Signals

The default action signal is layout-changed. It is emitted by GDL after panels are rearranged, detached, iconified or restored. Explicit GtkWidget signal actions remain available through the common contract.

Optional Dependency and Ownership

Configure with --with-gdl to enable the GTK2 gdl-1.0 package version 2.30.1. A build without GDL still parses the new tags and displays each dockitem in a labelled GTK2 frame, but layout input, output and rearrangement are unavailable.

The outer dock widget owns its GdlDock, GdlDockLayout, optional dock bar and all GdlDockItems. Closing or relaunching a window destroys that complete object graph before another instance is created.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe facilities specific to this tag.

Example 

<dock show-dockbar="true" switcher-style="both">
  <dockitem name="files" position="left" target="editor">
    <tree><label>Files</label></tree>
    <label>Files</label>
  </dockitem>
  <dockitem name="editor" position="center">
    <edit></edit>
    <label>Editor</label>
  </dockitem>
  <output file>/tmp/workspace-layout.xml</output>
  <variable>WORKSPACE_LAYOUT</variable>
</dock>

See examples/dock/dock for a complete runnable workspace. This widget was introduced in gtkdialog version 0.9.1.
