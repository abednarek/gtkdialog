assistant widget

A top-level GTK+ 2 GtkAssistant for guided multi-page tasks.

Definition 

<assistant tag_attr="value"...>
	page-widget...
	<default>page-number</default>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<action>activity</action>...
	<action signal="type">activity</action>...
	<output file>filename</output>
</assistant>

The assistant replaces the normal top-level window; it cannot be nested inside one. Each direct child is one page. Its variable contains the zero-based current page number.

Page Attributes

NameDescriptionValue
page-titlePage headingText
page-typePage role and navigationcontent, intro, confirm, summary or progress
completeWhether navigation may continuetrue or false

Actions and signals

The default action signal is apply. Explicit apply, cancel, close and prepare signals are supported. clear and removeselected return to page zero; refresh reads a page number and save writes it.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<assistant title="Setup">
	<vbox page-title="Welcome" page-type="intro" complete="true">
		<text><label>Welcome</label></text>
	</vbox>
	<vbox page-title="Ready" page-type="confirm" complete="true">
		<text><label>Ready to finish</label></text>
	</vbox>
	<variable>CURRENT_PAGE</variable>
	<action>exit:Apply</action>
</assistant>

This widget requires GTK+ 2.10 or later and was introduced in gtkdialog version 0.9.0.
