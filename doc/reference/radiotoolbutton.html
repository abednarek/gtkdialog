radiotoolbutton widget

An exclusive GTK+ 2 GtkRadioToolButton used as a direct child of a toolbar.

Definition 

<radiotoolbutton tag_attr="value"...>
	<label>text</label>
	<variable>varname</variable>
	<default>state</default>
	<input>command</input>
	<input file>filename</input>
	<output file>filename</output>
	<action signal="toggled">activity</action>...
</radiotoolbutton>

Radio tool buttons in one toolbar form an implicit group. Each toolbar has its own group, including a toolbar built again by an imperative loop or in a launched dialog. The variable value is true for the selected member and false for the others. The default signal is toggled. The legacy if true and if false action prefixes test this active state. If a prefixed action also has a condition attribute, the explicit condition is evaluated last and takes precedence for historical compatibility.

Named pointer, key and focus event actions use the same signals as other widgets, including button-press-event and key-press-event. GTK+ delivers these events to the tool item's internal button; gtkdialog forwards them to the logical radiotoolbutton, preserving its variable and action source.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<radiotoolbutton stock-id="gtk-justify-left">
	<label>Left</label>
	<variable>LEFT</variable>
	<default>true</default>
</radiotoolbutton>
<radiotoolbutton stock-id="gtk-justify-center">
	<label>Center</label>
	<variable>CENTER</variable>
</radiotoolbutton>

This widget was introduced in version 0.9.0 and requires GTK+ 2.4 or later.
