filechooserbutton widget

A GTK+ 2 GtkFileChooserButton for selecting a file or folder without a separate action button.

Definition 

<filechooserbutton tag_attr="value"...>
	<default>filename</default>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<sensitive>state</sensitive>
	<action>activity</action>...
	<action signal="type">activity</action>...
	<action function="type">parameter</action>...
	<output file>filename</output>
</filechooserbutton>

A default, command input or file input selects a local pathname. The variable and file output contain the selected pathname, or an empty string when no item is selected.

Tag Attributes

NameDescriptionValue
actionSelection modeopen or select-folder
titleTitle of the chooser dialogText
current-folderInitially displayed local folderPathname
filter-nameDisplay name of the optional filterText
filter-patternSemicolon- or comma-separated shell patterns*.png;*.jpg
filter-mime-typeSemicolon- or comma-separated MIME typesimage/png;image/jpeg
block-function-signalsDo not run actions for programmatic selectiontrue or false
file-monitorEmit a signal when an input file changestrue or false
auto-refreshRefresh when an input file changestrue or false

Writable GtkFileChooserButton and ancestor properties, including local-only, show-hidden and width-chars, can also be supplied as tag attributes. Availability follows the installed GTK+ 2 version.

Actions and signals

The default action signal is file-set. The refresh, save, clear and removeselected action functions read, store or clear the current pathname.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<filechooserbutton title="Select an image"
	filter-name="Images" filter-pattern="*.png;*.jpg">
	<variable>SELECTED_IMAGE</variable>
	<action>echo "$SELECTED_IMAGE"</action>
</filechooserbutton>

This widget requires GTK+ 2.6 or later and was introduced in gtkdialog version 0.9.0.
