grid widget

A GTK+ 2 GtkTable container exposed as <grid>. The distinct name preserves the existing gtkdialog <table> data widget and arranges direct child widgets in rows and columns.

Definition 

<grid rows="count" columns="count" tag_attr="value"...>
	widget...
	<variable>varname</variable>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
</grid>

At least one direct child is required. Children without explicit positions are placed in XML order from left to right, wrapping after the number of columns. Explicitly positioned children may overlap, matching GtkTable behaviour.

Writable GTK+ 2 GtkTable, GtkContainer and GtkWidget properties can also be used as tag attributes. Useful properties include row-spacing, column-spacing and homogeneous.

Signals and Functions

There is no default signal for this widget. General GtkWidget signals can be named explicitly in an action.

The enable, disable, show, hide and grabfocus functions are supported.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<grid rows="2" columns="2" row-spacing="8" column-spacing="12">
	<text row="0" column="0" x-options="fill" y-options="none">
		<label>Name</label>
	</text>
	<entry row="0" column="1">
		<variable>NAME</variable>
	</entry>
	<hbuttonbox row="1" column="0" column-span="2"
		layout-style="end">
		<button cancel></button>
		<button ok></button>
	</hbuttonbox>
</grid>

Notes

This is a GTK+ 2 GtkTable, not the GTK3 GtkGrid type. The <table> tag remains the existing multi-column data-selection widget.

This widget was introduced in version 0.9.0.
