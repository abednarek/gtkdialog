alignment widget

A GTK+ 2 GtkAlignment container. It positions and optionally scales one child within its allocated area.

Definition 

<alignment tag_attr="value"...>
	widget
	<variable>varname</variable>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
</alignment>

Exactly one direct child widget is required. Use an hbox or vbox as the child when several widgets must be aligned together.

Tag Attributes

Writable GTK+ 2 GtkAlignment, GtkContainer and GtkWidget properties can be used as tag attributes. The alignment-specific properties are:

The custom space-expand and space-fill attributes can override how an alignment is packed into an hbox or vbox.

Signals and Functions

There is no default signal for this widget. General GtkWidget signals can be named explicitly in an action.

The enable, disable, show, hide and grabfocus functions are supported.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<alignment xalign="1" yalign="1" xscale="0" yscale="0"
	right-padding="12" bottom-padding="12">
	<button ok></button>
	<variable>ALIGNED_AREA</variable>
</alignment>

Notes

This widget was introduced in version 0.9.0.
