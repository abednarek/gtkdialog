socket widget

A GTK+ 2 GtkSocket host for embedding an external XEmbed client inside a Gtkdialog layout. Unlike the retained gvim compatibility widget, this tag does not choose, launch or own a particular application.

Definition 

<socket tag_attr="value"...>
	<variable>varname</variable>
	<sensitive>state</sensitive>
	<action>activity</action>...
	<action signal="type">activity</action>...
</socket>

The variable is empty before realization and contains the socket's unsigned decimal X11 window ID once the widget is realized. A client that implements XEmbed can use that ID to attach itself. The ID is also exported before a realize action runs, so the action can launch the client directly.

Tag Attributes

Writable GtkSocket and ancestor properties can be supplied as tag attributes. Common custom attributes such as space-expand, space-fill, visible, block-function-signals and context-menu also apply. Availability follows the installed GTK+ 2 version.

Directives and value

The widget supports variable, sensitive and action directives. Its value is the socket ID; it has no input, output, refresh, save, clear or removeselected contract. Common state functions such as enable, disable, show, hide and grabfocus remain available.

Actions and signals

The default action signal is plug-added. The plug-removed signal can be selected explicitly. Gtkdialog keeps the socket alive after a client disconnects, so another client can attach to the same declared widget. Common GtkWidget signals, including realize, remain available explicitly.

Command actions are synchronous. A long-running client launched by an action must therefore be placed in the background. Gtkdialog owns neither the client process nor its shutdown; a surrounding script that requires explicit process cleanup should record and manage the child PID.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<socket width-request="640" height-request="400">
	<variable>SOCKET_ID</variable>
	<action signal="realize">xterm -into "$SOCKET_ID" &</action>
	<action>echo "XEmbed client attached"</action>
	<action signal="plug-removed">echo "XEmbed client detached"</action>
</socket>

This widget requires GTK+ 2 with the X11 backend and an XEmbed-capable client. It is not a GTK3 or Wayland integration. The tag was introduced in gtkdialog version 0.9.0.
