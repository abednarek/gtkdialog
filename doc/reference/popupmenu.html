popupmenu widget

Shared directives, GtkWidget signals, state and general functions, and action conditions are summarized in the common widget contract. The sections below document this tag's specific surface.

A top-level GtkMenu for standalone programs and widget context menus. The existing menu tag remains the submenu item used inside menu hierarchies. This widget was introduced in version 0.9.0.

Definition 

<popupmenu tag_attr="value"...>
	menu...
	menuitem...
	menuitemseparator...
</popupmenu>

"..." denotes acceptance of multiples of the same thing. At least one menu item is required.

Standalone use

Export the XML description and run it in the same way as a window program. The menu appears at the current pointer position without a surrounding window. Selecting an item runs its actions in source order. Pressing Escape or clicking outside the menu exits normally and prints EXIT="popupmenu" unless an action has already supplied another exit value.

POPUP_MENU='
<popupmenu>
	<menuitem icon-name="document-open">
		<label>Open</label>
		<action>exit:open</action>
	</menuitem>
	<menuitemseparator></menuitemseparator>
	<menuitem>
		<label>Cancel</label>
		<action>exit:cancel</action>
	</menuitem>
</popupmenu>'
export POPUP_MENU
gtkdialog --program=POPUP_MENU

Context-menu use

Set context-menu="NAME" on a widget which receives pointer or keyboard events and export NAME with a <popupmenu> description. Right click, the keyboard Menu key or Shift+F10 opens it. Wrap windowless content in an eventbox when it needs a clickable area. The menu is parsed on first use, cached, and destroyed with its originating widget. Changes to the exported description therefore apply after the originating widget is rebuilt. Menu actions use the same variable registry as the surrounding application, so they can invoke functions on its widgets.

ROW_MENU='
<popupmenu>
	<menuitem>
		<label>Remove selected row</label>
		<action>removeselected:FILES</action>
	</menuitem>
</popupmenu>'
export ROW_MENU

MAIN_DIALOG='
<window>
	<tree context-menu="ROW_MENU">
		<variable>FILES</variable>
		<label>File</label>
		<item>one.txt</item>
		<item>two.txt</item>
	</tree>
</window>'
export MAIN_DIALOG
gtkdialog --program=MAIN_DIALOG

For tree, iconview and the legacy table, right-clicking an item first selects it. In multiple-selection mode an already selected item preserves the complete selection, while an unselected item becomes the sole selection. Keyboard invocation preserves the current selection. Right-clicking empty space opens the widget menu without changing the current selection.

Tag Attributes

See the GtkMenu properties inherited from GtkWidget. The generic GTK+ property conversion described in syntax applies. Menu-item labels, icons, accelerator attributes, check/radio state and actions are defined on the child menuitem tags.

Directives and functions

popupmenu is a menu-shell container and has no application value of its own. Its menu items provide activation actions. The common widget state and general action contract applies where meaningful; in particular, closewindow may close a standalone popup menu by its variable. Context menus normally need no variable because their lifetime follows the originating widget. A context menu which declares a variable matching its source program can close itself with closewindow; the next invocation rebuilds it from the preserved program description.

Notes

A context-menu environment variable must contain exactly one <popupmenu> root. Defining a menu does not change pointer or keyboard handling for widgets without the explicit context-menu attribute.
