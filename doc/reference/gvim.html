gvim widget

A retained GTK+ 2/X11 compatibility widget that starts gvim --socketid ID and places the resulting editor window over a Gtkdialog placeholder. New applications should normally use a dedicated text editor component or launch an external editor explicitly.

Definition 

<gvim>
	<variable>varname</variable>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
</gvim>

Gtkdialog creates a GTK+ 2 socket, obtains its numeric X11 window ID and starts the first gvimPATH with that ID. The embedded window follows the placeholder's position and size and is destroyed with it.

The tag accepts directives between <gvim> and </gvim>, but its historical grammar does not accept tag attributes. It has no textual value, input, output, refresh, save or clear contract. A declared variable exists only so common state functions and action conditions can address the placeholder.

Common Contract

The common GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The initial visible tag attribute described there is unavailable because this legacy tag has no tag-attribute syntax; runtime show, hide, enable, disable and grabfocus remain available.

Example 

<window title="Embedded GVim">
	<vbox>
		<gvim>
			<variable export="false">EDITOR_PLACEHOLDER</variable>
		</gvim>
		<button cancel></button>
	</vbox>
</window>

This compatibility widget requires GTK+ 2 with X11 socket support and a GVim executable that accepts --socketid. It is not a GTK3 or Wayland integration.
