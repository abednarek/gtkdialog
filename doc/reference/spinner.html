spinner widget

A GTK+ 2 GtkSpinner for showing indeterminate activity.

Definition 

<spinner tag_attr="value"...>
	<default>Boolean state</default>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
	<action function="type">parameter</action>...
	<output file>filename</output>
</spinner>

The variable value and file output are true while the spinner is active and false while it is stopped. Boolean default and input values control that state.

Tag Attributes

Writable GtkSpinner and ancestor properties can also be supplied as tag attributes. Availability follows the installed GTK+ 2 version.

Actions and Signals

A spinner has no widget-specific default action signal. Common widget signals such as realize, show, button-press-event and button-release-event can be selected explicitly. The refresh and save action functions read configured input and write configured file output. clear and removeselected stop the spinner.

The active_is_true and active_is_false action conditions inspect whether the named spinner is currently running.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<spinner active="true" width-request="32" height-request="32">
	<variable>BUSY</variable>
</spinner>

This widget was introduced in gtkdialog version 0.9.0.
