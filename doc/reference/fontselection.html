fontselection widget

An embedded GTK+ 2 GtkFontSelection. Unlike fontbutton, it exposes the full font selector directly inside the application window.

Definition 

<fontselection font-name="Sans 12" preview-text="Preview text"...>
	<default>Pango font description</default>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<sensitive>state</sensitive>
	<action>activity</action>...
	<action signal="type">activity</action>...
	<output file>filename</output>
	<width>width-request</width>
	<height>height-request</height>
</fontselection>

Value and Directives

The exported value is the complete Pango font description returned by GTK+ 2, for example Sans Bold 12. The same format is accepted by default, font-name, command input and file input, and is written by save to an output file. A font must be available to the active GTK display; invalid descriptions are ignored with a warning.

The width and height directives set size requests. The selector has no label, item, clear or remove-selection operation.

Signals and Functions

The default gtkdialog signal is font-changed. GtkFontSelection has no equivalent class signal in GTK+ 2, so gtkdialog emits this logical signal when the native family, face or size controls change the complete font description. Refresh emits it only when the resulting value changed. The widget supports refresh and save in addition to the common visibility, sensitivity and focus functions. File monitoring provides the common file-changed signal and optional automatic refresh.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract.

Example 

<fontselection preview-text="GTKDialog preview">
	<default>Sans Bold 12</default>
	<variable>INTERFACE_FONT</variable>
	<action>echo "$INTERFACE_FONT"</action>
</fontselection>
