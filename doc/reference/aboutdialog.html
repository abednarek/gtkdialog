about dialog

A top-level GTK+ 2 GtkAboutDialog for application information, licensing and credits.

Definition 

<aboutdialog tag_attr="value"...>
	<item role="author|documenter|artist">person</item>...
	<default>response</default>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<action>activity</action>...
	<output file>filename</output>
</aboutdialog>

This element replaces the normal top-level window, cannot be nested and does not accept child widgets. Each item adds one credited person. The optional role is author (the default), documenter or artist.

Other standard writable GtkAboutDialog and GtkWindow properties are also accepted.

Actions and values

The variable is updated before default response actions run. The native Close button normally returns cancel, while the window manager returns delete-event. Responses do not implicitly close the dialog. Use exit for a root dialog or closewindow for a launched dialog. Defaults and inputs accept response names or integers. refresh reads input, save writes the response, and clear or removeselected clears it.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<aboutdialog program-name="GTKDialog GTK2" version="0.9.0-dev"
 comments="Build GTK+ 2 interfaces from XML.">
	<item role="author">GTKDialog contributors</item>
	<item role="documenter">Documentation contributors</item>
	<variable>ABOUT_RESPONSE</variable>
	<action>exit:response</action>
</aboutdialog>

The widget requires GTK+ 2.6 or later. wrap-license requires GTK+ 2.8; program-name uses the older GTK name API when building against GTK+ 2.6 or 2.10. Introduced in gtkdialog version 0.9.0.
