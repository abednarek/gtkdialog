sheet widget

An editable GTK+ 2 spreadsheet backed by the optional GtkSheet 3 library. It is a new tag and does not alter the historical table, grid or tree widgets.

Definition 

<sheet tag_attr="value"...>
	<width>viewport width</width>
	<height>viewport height</height>
	<item>cell|cell|...</item>...
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
	<output file>filename</output>
</sheet>

Other writable scalar GtkSheet properties can be supplied as normal tag attributes. Object-valued properties remain managed internally.

Data and value

Each item or input line is one row of pipe-separated cell text. Rows may contain fewer fields than the declared column count; missing cells are empty. A row with too many fields or an unavailable input rejects the complete refresh and preserves the last valid contents. File monitoring and automatic refresh use the common widget facilities.

Input sources are read in document order and item rows follow them. The widget grows when more rows arrive, but does not shrink its editable capacity. The exported variable contains the currently active cell text. The save function writes populated rows to the first output file, refresh reloads all declared sources, and clear erases the cells.

Signals

The default action signal is deactivate, emitted once when the current cell is committed before another cell becomes active. Explicit activate and changed actions are also available. GtkSheet emits changed while typing and again while committing, so it is intended for live feedback and can execute more than once per edit.

Optional dependency

The tag uses GtkSheet 3.5.1, the GTK2 branch of GtkSheet. Configure with --with-gtksheet to enable the gtksheet-3.0 package. A build without the library still parses the tag, displays a diagnostic placeholder and reports the unavailable optional feature.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<sheet columns="3" rows="12" title="Inventory"
  column-labels="Item|Quantity|Price"
  column-widths="260|100|100">
  <item>Apples|10|2.50</item>
  <item>Pears|8|3.00</item>
  <variable>INVENTORY_CELL</variable>
  <output file>/tmp/inventory.txt</output>
  <action>echo "Committed: $INVENTORY_CELL"</action>
</sheet>
