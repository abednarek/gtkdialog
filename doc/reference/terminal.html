terminal widget

Shared directives, GtkWidget signals, state and general functions, and action conditions are summarized in the common widget contract. The sections below document this tag's specific surface.

A VteTerminal packed inside a GtkScrolledWindow

Definition 

<terminal tag_attr="value"...>
	<variable>varname</variable>
	<height>value</height>
	<width>value</width>
	<input>command</input>
	<input file>filename</input>
	<sensitive>state</sensitive>
	<action>activity</action>...
	<action signal="type">activity</action>...
	<action function="type">parameter</action>...
</terminal>

"..." denotes acceptance of multiples of the same thing.

Signals

The default signal is "child-exited", emitted when the terminal detects that the child has exited.

A terminal can be placed in a page created with appendtab. Removing a page does not guarantee that its VTE child process stops immediately. A Close action for a terminal session can use hangupterminal:VARIABLE before removetab. This sends SIGHUP to the direct child recorded by the live VTE widget, or does nothing if it has already exited. See the tabbed terminal example. That example reads each page from a separate XML file and uses appendtabauto for the initial and subsequent tabs, so it needs no placeholder page. A program that ignores SIGHUP or runs in another process group may outlive its tab; the example is not a process supervisor.

The "file-changed" signal is emitted if file-monitor is true and the input file being monitored has changed.

The following signals are connected-up for all widgets:

button-press-event, button-release-event, configure-event, enter-notify-event, leave-notify-event, focus-in-event, focus-out-event, hide, show, realize, key-press-event, key-release-event, map-event, unmap-event

Notes

1. There exists an equivalently named "background-tint-color" VTE property but it doesn't accept strings so it's converted by Gtkdialog.

All new terminal attributes are optional. Without them VTE keeps its existing defaults. The palette sets base colours first; explicit foreground and background attributes above still take precedence. A palette is a colour list, not a named theme preset.

This is a non-mandatory widget that requires libvte support be built into Gtkdialog with --with-vte at configure time.

This widget was introduced in version 0.8.1.
