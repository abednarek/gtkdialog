imageview widget

A native GTK+ 2 raster-image viewer implemented with GtkDrawingArea, GtkScrolledWindow and GdkPixbuf. It provides zooming, aspect-preserving fit modes and drag panning without an additional widget library.

Definition 

<imageview tag_attr="value"...>
	<width>viewport width</width>
	<height>viewport height</height>
	<default>initial image filename</default>
	<variable>varname</variable>
	<input>command returning a filename</input>
	<input file>image filename</input>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
	<output file>image filename</output>
</imageview>

Custom Attributes

NameDescriptionValue
scale-modeInitial scaling policynone, manual, fit, fit-width or fit-height
zoomInitial manual scalefinite number from 0.01 to 32
zoom-stepMultiplier used by zoom actionsfinite number from 1.01 to 10
interpolationFilter used while scalingnearest, tiles, bilinear or hyper
backgroundViewport backgroundGTK colour specification
pan-buttonMouse button used for drag panning1 through 5
wheel-zoomEnable Ctrl+wheel zoomingtrue or false
hscrollbar-policyHorizontal scrollbar policy0, 1 or 2 (always, automatic, never)
vscrollbar-policyVertical scrollbar policy0, 1 or 2 (always, automatic, never)

The defaults are manual scale 1, zoom step 1.25, bilinear interpolation, middle-button panning and enabled Ctrl+wheel zooming. Both scrollbars default to GTK's automatic policy. fit displays the whole image, while fit-width and fit-height preserve the aspect ratio and may require one scrollbar.

Value and image I/O

A file input names an image to load. A command input reads an image filename from its first output line. Several inputs are evaluated in order and the last successfully loaded image wins. The variable contains the original filename, not an internally resolved search path. Assigning or selecting a value loads that filename.

refresh reloads the default and input sources, clear removes the current image, and save writes the original unscaled raster to the output filename. The filename extension selects the output format. A failed load leaves the previous valid image intact.

TypeDescriptionParameter

zoomoutEnter manual mode and divide the current displayed scale by zoom-stepImage-view variable
zoomresetEnter manual mode at the image's natural sizeImage-view variable

fitwidthFit the image width to the viewportImage-view variable
fitheightFit the image height to the viewportImage-view variable

Interaction and signals

Hold Ctrl and turn the wheel to zoom. Wheel events without Ctrl retain the normal GTK scrolling behaviour. Drag with the configured pan button to move the horizontal and vertical adjustments. The default pan button is the middle mouse button so primary clicks and context menus remain available to scripts.

The logical zoom-changed action runs after a scale action or a Ctrl+wheel step. The type-specific expose-event action runs after the visible raster is drawn. There is no default signal. Normal button-press-event and button-release-event actions receive the common pointer environment values.

Ownership and memory

The widget owns exactly one source pixbuf and its source filename. Replacing, clearing or destroying the widget releases them. Rendering creates only a temporary scaled pixbuf for the exposed rectangle, so zooming a large image does not retain another full-size scaled copy. The surrounding scrolled window and viewport remain owned by the GTK widget hierarchy.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<imageview scale-mode="fit" zoom-step="1.25" background="#20242a">
	<width>640</width>
	<height>360</height>
	<input file>/tmp/preview.png</input>
	<output file>/tmp/saved-preview.png</output>
	<variable>PREVIEW_IMAGE</variable>
</imageview>
<button>
	<label>Zoom in</label>
	<action function="zoomin">PREVIEW_IMAGE</action>
</button>

A runnable example is installed with the source distribution under examples/imageview/imageview.

This widget was introduced in gtkdialog version 0.9.0.
