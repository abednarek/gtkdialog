tasklist widget

A native GTK+ 2 X11 task list backed by the optional libwnck 2 library. It adds a new tag and does not alter any historical gtkdialog widget.

Definition 

<tasklist tag_attr="value"...>
	<variable>varname</variable>
	<default>window XID</default>
	<input>shell command</input>
	<input file>filename</input>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
	<output file>filename</output>
</tasklist>

Custom Attributes

NameDescriptionValue
screenX11 screen whose windows are shownZero-based integer; default 0
groupingCombine buttons belonging to one applicationnever, auto or always
grouping-limitApproximate button width below which automatic grouping beginsNon-negative integer
include-all-workspacesInclude windows outside the active workspacetrue or false; default false
switch-workspace-on-unminimizeSwitch to a minimized window's workspace when activating ittrue or false; default true
button-reliefRelief of native task buttonsnormal, half or none
minimum-widthRetained libwnck 2 minimum-width controlNon-negative pixels
minimum-heightRetained libwnck 2 minimum-height controlNon-negative pixels

The two minimum-size functions are deprecated by libwnck but remain useful for GTK2 panel layouts. Standard writable scalar GtkWidget properties, such as width-request and height-request, remain available.

Value, Input and Output

The variable contains the unsigned decimal XID of the active managed window, or an empty string when no window is active. A default, command input or file input containing an XID activates that window. Input files use the common monitoring and automatic-refresh facilities. The refresh function updates libwnck's view and re-reads inputs; save writes the current active XID to the first output file.

clear and removeselected intentionally do nothing: a task list must never close or modify another application's window as a side effect of a generic gtkdialog value operation.

Signals

The default action signal is active-window-changed. It runs when the selected WnckScreen reports a different active window. Explicit GtkWidget signal actions remain available through the common contract.

Optional Dependency and Ownership

Configure with --with-libwnck to enable GTK2 libwnck-1.0 version 2.30 or later. A build without libwnck still parses the tag and displays a diagnostic placeholder.

WnckScreen is a borrowed process-wide singleton. The task-list widget owns neither the screen nor desktop windows. Its screen signal is connected with the task-list GtkWidget as the tracking object, so closing or relaunching the containing window disconnects the old callback automatically.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe facilities specific to this tag.

Example 

<tasklist grouping="auto" include-all-workspaces="true">
  <variable>ACTIVE_WINDOW_XID</variable>
  <output file>/tmp/active-window-xid</output>
  <action signal="active-window-changed">
    echo "Active XID: $ACTIVE_WINDOW_XID"
  </action>
</tasklist>

See examples/tasklist/tasklist for a complete runnable desktop-panel example. This widget was introduced in gtkdialog version 0.9.0.
