offscreenwindow

A GTK+ 2 GtkOffscreenWindow program root that renders one declarative widget hierarchy into an image without placing a normal window on the desktop.

Definition 

<offscreenwindow tag_attr="value"...>
	one child widget hierarchy
	<width>minimum rendered width</width>
	<height>minimum rendered height</height>
	<sensitive>state</sensitive>
	<output file>image filename</output>
	<action signal="type">activity</action>...
	<variable>program name</variable>
</offscreenwindow>

Rendering and output

The root is shown and realized internally so GTK can allocate and draw its child, but no desktop window is displayed. Width and height set the minimum snapshot dimensions; otherwise the child's natural requisition is used. Applicable writable GtkWidget and GtkContainer properties, including border-width, can be supplied as tag attributes. GtkWindow-only presentation, title, icon and taskbar properties have no useful off-screen meaning and should not be used.

save writes the current rendering to the first output file. The filename extension selects the GdkPixbuf writer; .jpg is treated as JPEG. The widget must have completed its first draw before it can be saved. A short timer, as in the example below, is the deterministic way to take the initial snapshot. refresh queues a redraw of the child. clear and removeselected intentionally do nothing, because destroying the child would destroy the declared program.

Signals and lifecycle

The default action signal is damage-event, emitted after an already rendered child changes. Initial realization is available explicitly as realize, but the first draw is not guaranteed to produce a damage event. Common GtkWidget signals and state actions remain available.

The variable names the program root and is not exported as a widget value. The normal launch and closewindow lifecycle applies, including closing and relaunching the same off-screen program. Launching an already active instance keeps the existing one; presentwindow has no visual effect. The general exit action remains synchronous.

Ownership and availability

GtkOffscreenWindow owns its one child hierarchy. Each save operation receives a new GdkPixbuf reference from GTK, writes it, and releases it immediately. Closing the root therefore releases the child, its variables, timers, monitors and any widget-owned resources through the existing top-level lifecycle.

This tag requires GTK+ 2.20 or later and remains GTK2-only.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe facilities specific to this tag.

Example 

<offscreenwindow border-width="12">
  <vbox>
    <text><label>Rendered without a desktop window</label></text>
    <timer milliseconds="true" interval="100" visible="false">
      <action function="save">SNAPSHOT</action>
      <action>exit:OK</action>
    </timer>
  </vbox>
  <output file>/tmp/gtkdialog-snapshot.png</output>
  <variable>SNAPSHOT</variable>
</offscreenwindow>

See examples/offscreenwindow/offscreenwindow for a complete runnable example. This widget was introduced in gtkdialog version 0.9.0.
