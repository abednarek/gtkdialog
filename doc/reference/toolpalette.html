toolpalette widget

A GTK+ 2.20 GtkToolPalette container. It arranges expandable groups of the existing gtkdialog tool-item widgets.

Definition 

<toolpalette orientation="vertical" toolbar-style="both"...>
	one-or-more toolitemgroup widgets
	<variable>varname</variable>
	<width>width-request</width>
	<height>height-request</height>
</toolpalette>

Tag Attributes

Writable scalar GtkToolPalette, GtkContainer and GtkWidget properties are available. Important properties include orientation (horizontal or vertical), toolbar-style (icons, text, both or both-horizontal) and icon-size. Common packing attributes are also available.

Directives, Signals and Functions

The optional variable names the palette and exports an empty value. Width and height directives set its size request. The palette has no default signal and no type-specific value, input, output or value functions. Contained tool items retain their existing click, toggle, menu and common action behavior.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. Visibility and sensitivity functions target the named palette.

Scrolling

GtkToolPalette implements GTK+ scrolling adjustments. Place it directly in a scrolledwindow when the groups can exceed the available area; gtkdialog connects it without an intermediate viewport.

Example 

<scrolledwindow hscrollbar-policy="never">
	<toolpalette orientation="vertical" toolbar-style="both">
		<toolitemgroup exclusive="true" expand="true">
			<toolbutton stock-id="gtk-new"><label>New</label></toolbutton>
			<toolbutton stock-id="gtk-open"><label>Open</label></toolbutton>
			<label>Files</label>
		</toolitemgroup>
		<variable>PALETTE</variable>
	</toolpalette>
</scrolledwindow>

This widget requires GTK+ 2.20 or later and was introduced in gtkdialog version 0.9.0.
