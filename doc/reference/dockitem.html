dockitem widget

A named, rearrangeable panel used as a direct child of the optional dock container. Each dockitem owns exactly one ordinary gtkdialog widget.

Definition 

<dockitem tag_attr="value"...>
	widget
	<label>panel title</label>
	<variable>varname</variable>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
</dockitem>

The child widget precedes the directives. Names must be unique within a dock; explicit names are required when a saved layout will be loaded later.

Custom Attributes

NameDescriptionValue
nameStable identity in targets and layout filesUnique text name; generated when omitted
stock-idPanel and switcher iconGTK2 stock identifier
positionInitial placementcenter, top, bottom, left, right or floating
targetNamed panel relative to which this item is placedDockitem name; XML order is not significant
docking-paramInitial splitter size passed to GDLNon-negative integer
behaviorGrip and placement restrictionsFlags separated by spaces, commas or |
floating-x, floating-yInitial detached-window positionSigned pixel coordinates
floating-width, floating-heightInitial detached-window sizePositive pixel counts; defaults 320 and 240

The behavior flags are normal, never-floating, never-vertical, never-horizontal, locked, cant-dock-top, cant-dock-bottom, cant-dock-left, cant-dock-right, cant-dock-center, cant-close, cant-iconify and no-grip.

Writable scalar GdlDockItem and inherited GTK2 properties can be supplied as normal attributes after the dedicated constructor and placement attributes are consumed. This includes native properties such as resize, locked, preferred-width and preferred-height when supported by GDL 2.

Placement

An explicitly centred item becomes the stable main area even when it appears later in the XML. Other target dependencies are resolved before attachment, so a dockitem may refer to another item declared later. A missing target or a target cycle produces a warning and leaves the affected panel attached to the main dock instead of discarding its content.

Value and signals

The exported variable contains the dockitem's stable name. The default action signal is selected, emitted when the item becomes the selected page of a GDL switcher. Dockitems have no type-specific input, output, refresh, save or clear functions; data operations remain those of their child widget.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. Common state functions address the complete panel.

Example 

<dockitem name="output" position="bottom" target="editor"
  docking-param="160" stock-id="gtk-info"
  behavior="cant-close|cant-iconify">
  <text><label>Build output</label></text>
  <label>Output</label>
  <variable>OUTPUT_PANEL</variable>
  <action>echo "Selected $OUTPUT_PANEL"</action>
</dockitem>

This widget was introduced in gtkdialog version 0.9.0.
