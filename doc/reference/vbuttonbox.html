vbuttonbox widget

A GTK+ 2 GtkVButtonBox arranges related buttons vertically using a toolkit-standard layout.

Definition 

<vbuttonbox tag_attr="value"...>
	widget...
	<variable>varname</variable>
	<sensitive>state</sensitive>
	<action signal="type">activity</action>...
</vbuttonbox>

Tag Attributes

See the GtkVButtonBox and ancestor class properties. The following gtkdialog attributes add named layouts and secondary-child placement:

NameDescriptionValueDefault
layout-styleButton placementdefault, spread, edge, start, end or centerGTK+ setting
secondaryPlace a direct child separately from the main grouptrue or falsefalse

The secondary attribute belongs on a direct child, not on the button box. The center layout requires GTK+ 2.12 or later.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<vbuttonbox layout-style="center" spacing="6">
	<button><label>New</label></button>
	<button><label>Open</label></button>
	<button><label>Close</label></button>
</vbuttonbox>

This widget was introduced in version 0.9.0.
