status icon

A GTK+ 2 GtkStatusIcon for a desktop notification area or system tray.

Definition 

<statusicon tag_attr="value"...>
	<label>fallback tooltip</label>
	<default>image source</default>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<action>activity</action>...
	<output file>filename</output>
</statusicon>

The status icon is not a window child in GTK+. Gtkdialog represents it with a zero-size logical widget so that normal variable lookup, window ownership, state functions, conditions and destruction remain deterministic. Destroying or relaunching the containing window destroys and recreates its status icon.

The common visible and sensitive states apply to the logical icon. Hiding it removes it from the notification area; an insensitive icon ignores activation and popup actions.

Image value and directives

The variable, default, command/file input and saved output use one source string. icon:name selects a theme icon, stock:name selects a GTK stock ID, and file:path loads a file. A bare value is treated as an icon name. clear and removeselected remove the current image; refresh, save and fileselect use the same value format. A label supplies a plain tooltip when no tooltip attribute is present.

Signals and actions

The default signal is activate, normally emitted by a primary click. It is also emitted by activate:VARIABLE. Explicit button-press-event, button-release-event, popup-menu and size-changed actions follow their native GtkStatusIcon signals. Pointer actions export the same BUTTON, PTR_BTN, coordinate and modifier variables as ordinary widgets. The configured context menu is positioned by GTK at the status icon.

Common Contract

Common directives, proxy GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. Native status-icon signals are listed above because the underlying object is not a GtkWidget.

Example 

<statusicon icon-name="dialog-information"
 title="GTKDialog" tooltip-text="GTKDialog is running"
 context-menu="TRAY_MENU">
	<variable>TRAY_ICON</variable>
	<action>presentwindow:MAIN_DIALOG</action>
	<action signal="popup-menu">echo "opening menu"</action>
</statusicon>

The widget requires GTK+ 2.10 or later. Desktop environments may hide status icons or require a notification-area host. Introduced in gtkdialog version 0.9.0.
