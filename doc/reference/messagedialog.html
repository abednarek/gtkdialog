message dialog

A top-level GTK+ 2 GtkMessageDialog for standard messages, warnings, errors and questions.

Definition 

<messagedialog tag_attr="value"...>
	<label>primary message</label>
	<default>response</default>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<action>activity</action>...
	<action signal="response">activity</action>...
	<output file>filename</output>
</messagedialog>

This element replaces the normal top-level window and cannot be nested. Its variable contains the latest named response.

Tag attributes

NameDescriptionValue
message-typeMessage icon and roleinfo, warning, question, error or other
buttonsStandard response buttonsnone, ok, close, cancel, yes-no or ok-cancel
secondary-textAdditional explanatory textText; requires GTK+ 2.6 or later
default-responseResponse activated by Enterok, cancel, close, yes, no, apply, help, accept, reject or an integer

Standard writable GtkWindow properties, including title, are also accepted. The label directive is the primary message, not the title.

Actions and values

The default action signal is response. The response value is stored before actions run. Responses do not implicitly close the dialog; use exit for a root dialog or closewindow for a launched dialog. Defaults and inputs accept response names or integers. refresh reads configured input, save writes the response, and clear or removeselected clears it.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<messagedialog title="Confirm" message-type="question"
 buttons="yes-no" default-response="yes"
 secondary-text="The project remains GTK2-only.">
	<label>Continue?</label>
	<variable>ANSWER</variable>
	<action>exit:response</action>
</messagedialog>

Introduced in gtkdialog version 0.9.0.
