recent chooser menu

A labelled menu item containing a GTK+ 2 GtkRecentChooserMenu for resources stored by the desktop recent manager.

Definition 

<recentchoosermenu tag_attr="value"...>
	<label>submenu label</label>
	<default>URI</default>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<action>activity</action>...
	<output file>filename</output>
</recentchoosermenu>

The tag is valid wherever a menu item is accepted, such as inside a menu in a menu bar or popup menu. The labelled menu item owns its native chooser submenu and all installed recent filters. The chooser reads the current user's shared recent-resource history; item is not used to populate that history.

Tag attributes

NameDescriptionValue
local-onlyShow only local resourcesBoolean
show-privateShow private resourcesBoolean
show-not-foundShow missing resourcesBoolean
show-tipsShow resource tooltipsBoolean
show-iconsShow resource iconsBoolean
limitMaximum displayed resourcesInteger
sort-typeRecent-resource ordernone, mru or lru
show-numbersPrefix the first ten resources with mnemonic numbersBoolean
filter-nameOptional filter labelText
filter-patternFilename patternsComma- or semicolon-separated patterns
filter-mime-typeAllowed MIME typesComma- or semicolon-separated MIME types

Actions and values

The variable and file output contain the single current resource URI. Defaults and inputs establish a logical URI for output and actions without marking a visible menu entry; activating a recent entry replaces it with the URI reported by GTK+. The default action signal is item-activated; selection-changed may be named explicitly for GTK+ operations that emit it. refresh reads configured input, save writes the current URI, and clear or removeselected only clears that value. These actions never delete entries from the desktop history.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<menu label="File">
	<recentchoosermenu local-only="true" show-numbers="true" limit="10"
	 filter-name="Documents" filter-pattern="*.txt;*.md;*.pdf">
		<label>Recent documents</label>
		<variable>RECENT_URI</variable>
		<action>echo "$RECENT_URI"</action>
	</recentchoosermenu>
</menu>

The menu requires GTK+ 2.10 or later. Introduced in gtkdialog version 0.9.0.
