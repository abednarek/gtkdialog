toolitemgroup widget

A GTK+ 2.20 GtkToolItemGroup used as a direct child of toolpalette.

Definition 

<toolitemgroup exclusive="false" expand="false"...>
	one-or-more tool-item widgets
	<label>group heading</label>
	<variable>varname</variable>
	<input>command</input>
	<input file>filename</input>
	<output file>filename</output>
</toolitemgroup>

Tag Attributes

NameDescriptionValues
exclusiveCollapse other exclusive groups when this group expandstrue or false
expandGive the group additional palette spacetrue or false
collapsedInitial collapsed statetrue or false
ellipsizeHeading ellipsizationPangoEllipsizeMode nickname or numeric enum value
header-reliefHeading button reliefGtkReliefStyle nickname or numeric enum value

Writable scalar ancestor properties and common packing attributes are also available. Each child must be a toolbutton, toggletoolbutton, radiotoolbutton, menutoolbutton, separatortoolitem or toolitem.

Tool-item Packing

The existing tool-item expand and homogeneous attributes also configure their group packing. Use palette-fill="true|false" and palette-new-row="true|false" for the remaining GtkToolItemGroup child properties.

Value, Directives and Functions

The group heading is its textual value. Label, default, command input and file input set it; file output and save write it. Refresh reloads input, while clear and removeselected clear the heading. The group has no default signal. Its tool-item children retain their normal action behavior.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract.

Example 

<toolitemgroup collapsed="false" expand="true">
	<toolbutton stock-id="gtk-cut"><label>Cut</label></toolbutton>
	<toggletoolbutton stock-id="gtk-bold" palette-new-row="true">
		<label>Bold</label>
	</toggletoolbutton>
	<label>Formatting</label>
	<variable>FORMAT_GROUP</variable>
</toolitemgroup>

This widget requires GTK+ 2.20 or later and was introduced in gtkdialog version 0.9.0.
