viewport widget

A public GTK+ 2 GtkViewport container. It provides the scrolling capability needed by ordinary child widgets that do not implement scrolling adjustments themselves.

Definition 

<viewport shadow-type="in"...>
	widget
	<variable>varname</variable>
	<width>viewport-width</width>
	<height>viewport-height</height>
</viewport>

Exactly one direct child is required. Use an hbox, vbox or grid to group several widgets under one viewport.

Tag Attributes

Writable scalar properties of GtkViewport and its GtkBin, GtkContainer and GtkWidget ancestors can be used as tag attributes. The most useful properties are:

NameDescriptionValues
shadow-typeBorder drawn around the childnone, in, out, etched-in, etched-out, or numeric enum value
space-expandPack widget expanding into spacetrue or false
space-fillPack widget filling spacetrue or false
block-function-signalsBlock signal emissions from functionstrue or false
context-menuPopup menu program for pointer or keyboard invocationExported variable containing a <popupmenu> program

The object-valued hadjustment and vadjustment properties are managed by GTK+ and are not accepted as textual tag attributes.

Directives, Signals and Functions

The optional variable directive names the viewport for common functions and exports an empty value. The width and height directives set its size request. This container has no default signal and no type-specific value, input, output, refresh, save, clear or movement functions. Its child retains its normal value and action behavior.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. Visibility and sensitivity functions target the named viewport.

Example 

<scrolledwindow hscrollbar-policy="never"
	vscrollbar-policy="automatic">
	<viewport shadow-type="in">
		<vbox>
			<text><label>Scrollable content</label></text>
			<text height-request="500">
				<label>Long child</label>
			</text>
		</vbox>
		<variable>VIEWPORT</variable>
	</viewport>
</scrolledwindow>

Notes

When the viewport is the direct child of scrolledwindow, the surrounding GtkScrolledWindow supplies both adjustments through GTK+ 2's native scroll-adjustment mechanism. Gtkdialog does not add another viewport.

This widget was introduced in version 0.9.0.
