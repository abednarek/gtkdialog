menutoolbutton widget

A GTK+ 2 GtkMenuToolButton with a clickable main area and a separate arrow that opens a menu. It is used as a direct child of a toolbar.

Definition 

<menutoolbutton tag_attr="value"...>
	(menuitem | menu | menuitemseparator)...
	<label>text</label>
	<variable>varname</variable>
	<sensitive>state</sensitive>
	<action signal="clicked">activity</action>...
</menutoolbutton>

At least one direct menu child is required. A nested menu creates a submenu, using the same syntax as in a menubar.

The default action signal is clicked and belongs to the main button. A named menutoolbutton can also be clicked with <action function="activate">name</action>. Clicking the arrow opens the menu without running the main action; selecting an entry runs that menu item's action.

Named pointer, key and focus event actions use the same signals as other widgets, including button-press-event and key-press-event. GTK+ delivers these events to the internal main and arrow buttons; gtkdialog forwards them to the logical menutoolbutton, preserving its variable and action source.

Tag Attributes

See the GtkMenuToolButton, GtkToolButton and ancestor class properties. Common attributes include stock-id, icon-name, tooltip-text, use-underline, is-important, expand and homogeneous. Availability follows the installed GTK+ 2 version.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. The sections above describe the facilities specific to this tag.

Example 

<menutoolbutton stock-id="gtk-open" is-important="true">
	<menuitem>
		<label>Recent report</label>
		<action>echo report</action>
	</menuitem>
	<menuitemseparator></menuitemseparator>
	<menu>
		<menuitem><label>Example one</label></menuitem>
		<menuitem><label>Example two</label></menuitem>
		<label>Examples</label>
	</menu>
	<label>Open</label>
	<action>echo open</action>
</menutoolbutton>

This widget was introduced in version 0.9.0 and requires GTK+ 2.6 or later.
