handlebox widget

A GTK+ 2 GtkHandleBox container. The user can drag its handle to detach one child into a floating window and move it back to attach it again.

Definition 

<handlebox handle-position="left" snap-edge="top"...>
	widget
	<variable>varname</variable>
	<width>width-request</width>
	<height>height-request</height>
	<action signal="child-detached">command</action>
	<action signal="child-attached">command</action>
</handlebox>

Exactly one direct child is required. A GtkToolbar is the usual child, but any GTK+ widget accepted by GtkHandleBox may be used.

Tag Attributes

Writable scalar properties of GtkHandleBox and its GtkContainer and GtkWidget ancestors can be used as tag attributes. The most useful properties are:

NameDescriptionValuesSince
handle-positionSide containing the drag handleleft, right, top, bottom, or numeric enum value 0.9.0
snap-edgeEdge used when the floating child approaches its original positionleft, right, top, bottom, or numeric enum value 0.9.0
shadow-typeFrame around the attached childGtkShadowType enum nickname or numeric value 0.9.0
space-expandPack widget expanding into spacetrue or false 0.9.0
space-fillPack widget filling spacetrue or false 0.9.0

Directives

The optional variable directive names the handle box for common functions and exports an empty value. The width and height directives set its size request. This container has no type-specific input, output, refresh, save, clear or movement functions.

Signals

This widget has no default signal. Actions may explicitly use signal="child-detached" and signal="child-attached". Common GtkWidget signals are available as described below.

Common Contract

Common directives, GtkWidget signals, state and general functions, and action conditions are documented in the common widget contract. Visibility and sensitivity functions target the named handle box.

Example 

<handlebox handle-position="left" snap-edge="top" shadow-type="out">
	<toolbar>
		<toolbutton stock-id="gtk-new"><label>New</label></toolbutton>
		<toolbutton stock-id="gtk-open"><label>Open</label></toolbutton>
	</toolbar>
	<variable>TOOLBAR_HANDLE</variable>
	<action signal="child-detached">echo "detached"</action>
	<action signal="child-attached">echo "attached"</action>
</handlebox>

Notes

Detaching and reattaching are interactive window-manager operations, so the exact floating-window decoration and snapping feedback depend on the GTK+ 2 theme and X11 window manager. This widget is intended for optional detachable tool areas, not as a general layout container.

This widget was introduced in version 0.9.0.
